# Перевод Гоблина: ru и en

Как устроены два языка и как добавлять текст. Остальные документы: [бэкенд](backend.md) ·
[прогон](progon.md) · [фронтенд](frontend.md) · [карта файлов](structure.md).

## Два языка — два адресата

| Кому | Функция | Откуда язык |
|---|---|---|
| человеку — интерфейс, его ошибки | `t()`, `tn()` | cookie `goblin_lang` (меню «Настройки» → «Язык»); нет cookie — русский |
| агенту и модели — инструкции, задания, лента, ответы ведущему | `ta()`, `tna()` | язык проекта `projects.lang` (свойства проекта → «Язык агентов») |

**Язык по адресату.** Если отвечаем агенту, `t()` тоже говорит на языке проекта: ошибки сервера агент
читает на том же языке, что и весь прогон. Флаг ставит `dispatch()` (`lib/api/router.php`) через
`langForAgent(true)`, когда:
- спросили операцию простого пути (`simpleOp()`);
- `docs.run` или `docs.get` пришли без входа и без cookie языка (`docsForAgent()`) — это агент по ссылке;
- у вызывающего пропуск ведущего или worker (`lead`, `worker`).

Человек без cookie по-прежнему получает русский. Язык проекта ставит `requireProject()`
(`langAgents()`); фоновое задание ИИ берёт язык человека из своего контекста (`aiJobLang()`).

## Где что лежит

| Где | Как |
|---|---|
| словари | `lang/ru/<часть>*.json` и `lang/en/<часть>*.json` — плоский JSON `{"ключ": "текст"}` |
| JS | `import { t, tn, lang } from 'goblin/core/i18n.js'` → `t('editor.panel.folder_name')` |
| HTML-вид (`views/…`) | `{{t:editor.settings.title}}` — в тексте и в атрибутах (`title`, `placeholder`, `aria-label`) |
| PHP | `t('server.folder.not_found')`, `tn('server.steps', $n)`, `ta('agents.go.passed')` — `lib/core/i18n.php` |
| подстановка | `t('editor.folder.delete_ask', { name })` ↔ `"Удалить папку «{name}»?"` |
| число со словом | `tn()` / `tna()` ↔ `ключ.one/few/many` (ru) и `ключ.one/other` (en); `{n}` — число |
| длинные тексты агентам | `instructions/<язык>/*.md`, по частям `<!-- part:… -->` и `<!-- rule:… -->`; файл на языке — `langFile()` |
| md-документы | `md_backend/ru/` и `md_backend/en/`, имена одинаковые |
| каталог схем | перевод заготовки и раздела — поле `i18n` (`{"en": {...}}`) в базе |

Браузер получает словарь прямо в странице (`langScript()` в `lib/core/i18n.php`) — до загрузки модулей,
поэтому `t()` работает и на верхнем уровне модуля. Нет перевода — русский текст, нет и его — сам ключ.
Язык интерфейса в JS — `lang` из `core/i18n.js` (например, `<html lang>` в экспорте HTML, порядок сортировки).

## Ключ и файл словаря

**Ключ** — `часть.место.смысл`, латиница, `snake_case`: `editor.panel.folder_name`,
`agents.go.passed`, `server.element.no_title`. Часть — первое слово ключа и начало имени файла
словаря: ключи `editor.*` лежат только в `lang/*/editor*.json`. Файл можно дробить по смыслу и по автору:

| Часть | Для чего | Файлы |
|---|---|---|
| `editor` | редактор, `public/src/**`, `views/editor/**` | `editor.json`, `editor-<место>.json`; новые ключи 30.09 — `editor-d.json`, `editor-e.json` |
| `admin` | админка | `admin.json`, `admin-catalog.json`, `admin-c.json` |
| `account` | кабинет | `account.json`, `account-c.json` |
| `server` | ошибки и сообщения сервера человеку | `server.json`, `server-guard.json`, `server-a.json`, `server-c.json` |
| `agents` | всё агентам и модели: прогон, задания, лента, ИИ | `agents.json`, `agents-engine.json`, `agents-a.json`, `agents-b.json` |
| `docs` | страница документации | `docs.json` |
| `common` | общие слова (Закрыть, Отмена…) | `common.json` — только читать, новые не добавлять |

Суффикс `-a`…`-e` — файл одного автора: так параллельные правки не трогают один и тот же json.
Кто правит свою часть кода — добавляет ключи в свой файл; менять чужой ключ можно, только если меняется
его текст.

## Правила

1. **Русский текст — буква в букву прежний**, с «ёлочками» и многоточием: проверки сверяют надписи.
2. Ключ добавляется **сразу в оба словаря** — ru и en.
3. Фраза — одним ключом, с подстановками `{имя}`. Перевод из кусков не склеивать.
4. Числа со словами — только `tn()` / `tna()`.
5. **Текст агенту и модели** (`lib/engine/`, `lib/ai/`, `lib/api/simple.php`, `lib/api/instructions.php`) —
   `ta()`; человеку — `t()`. Разбор ответов агента понимает оба языка.
6. **Не переводить:** комментарии; имена операций API, поля JSON, классы CSS, типы элементов в данных
   (`block`, `decision`); данные из базы (названия проектов, папок, блоков); записи журнала и ленты,
   уже сохранённые в базу; `config.txt`; утилиту `lib/cli/` (про запас).
7. Своя переменная `t` в функции (время, доля) — переименовать до вызова перевода.
8. Английский — простой и короткий, Sentence case («Create folder»), без канцелярита.

## Слова протокола прогона

Их печатает сервер (`lang/*/agents.json`, ключи `agents.go.*`), читают ведущий и worker
(`instructions/*/прогон.md`), ищут сторож (`bin/lead-watch.sh`) и разбор ответов. Это договор:
менять только осознанно, со сменой эталонов `tests/v2/golden/` (`node tests/v2/check-golden.mjs --update`).

| Русский | English |
|---|---|
| `━━ СЛЕДУЮЩИЙ: блок N «…» · задание N.K · выдан` | `━━ NEXT: block N “…” · task N.K · issued` |
| `ПРОГОН rN НАЧАТ` · `ПРОГОН ПРОЙДЕН` · `СХЕМА НЕ ГОТОВА` | `RUN rN STARTED` · `RUN PASSED` · `SCHEME NOT READY` |
| `ОПИСАНИЕ ПРОГОНА` · `СХЕМА КРАТКО` | `RUN DESCRIPTION` · `SCHEME OUTLINE` |
| `СТОИТ` · `РОМБ — Jev не решил, реши сам` · `ШЛЮЗ` | `STUCK` · `DECISION — Jev did not decide, decide yourself` · `GATEWAY` |
| `ТИШИНА` · `ПРОГОН ЗАКРЫТ` · `НЕТ СТАТУСА` (сторож) | `SILENCE` · `RUN CLOSED` · `NO STATUS` |
| `задание по ссылке АДРЕС` · `блок N сейчас не выдан` | `task at link ADDRESS` · `block N is not issued now` |
| `повтор: задание N.K уже принято…` · `повтор: блок N уже принят…` | `repeat: task N.K was already accepted…` · `repeat: block N was already accepted…` |
| `Вход:` · `(прежний вход)` · `Круг 2 — вернул ромб …` | `Input:` · `(previous input)` · `Round 2 — decision … sent it back` |
| `Рабочая папка:` · `Ответь одной строкой вида:` | `Work folder:` · `Answer in one line like:` |
| `ОТВЕТ worker: 137.3: …` · `ОШИБКА: задание 137.3 — …` · `Замечание: … — 76.4: …` | `WORKER ANSWER: 137.3: …` · `ERROR: task 137.3 — …` · `Note: … — 76.4: …` |
| статус `прогон rN · running · принято шагов: 3 · сейчас: …` | `run rN · running · accepted steps: 3 · now: …` |
| `ok: блок 137 принят · задание 137.3` · `ромб 138 → нет` | `ok: block 137 accepted · task 137.3` · `decision 138 → no` |
| образец `a=<число> <слово> <файл> <текст>` · `вызовов=<число>` | `a=<number> <word> <file> <text>` · `calls=<number>` |
| условие ромба `содержит` · `начинается` · `кончается` | `contains` · `starts with` · `ends with` |
| ветка `да` / `нет` (`branch=`) | `yes` / `no` |

Разбор понимает оба языка: образцы, условия, `calls=`/`вызовов=`, приставки `ОТВЕТ worker:` и
`WORKER ANSWER:`, ветки `yes/no/да/нет`. Имена `.попытки/`, `схема.txt`, `рисование.md` не переводятся —
это пути.

## Что остаётся по-русски — и почему

`check-i18n.php` считает русские строки в коде. Это не долг перевода, если строка — не текст для экрана:

| Что | Где | Почему остаётся |
|---|---|---|
| утилита `goblin` | `lib/cli/**` | про запас, не переводится |
| слова разбора ответа | `lib/api/simple.php`, `lib/engine/checks/{cond,form}.php`, `vars.php` | сервер понимает и русский ответ агента |
| прежние русские коды и синонимы | `notFoundText()` (`lib/access/rights.php`), `docsGet()` (`ведущий`, `воркер`) | старые вызовы и ссылки продолжают работать |
| имена файлов | `рисование.md`, `схема.txt`, `.попытки/` | это пути |
| подписи по умолчанию в константах | `KINDS` (`lib/elements/kinds.php`), `RUN_ENVS`, `ROLE_SCHEMES` | экран и агенты берут свои ключи (`editor.kinds.*`, `agents.env.*`, `agents.role.*`) |
| внутренние ключи и метки отладки | `panel.js` (ключи секций), `voice.js` (`console`) | человеку не показываются |

Данные из базы и уже записанные строки ленты и журнала хранятся на языке, на котором их записали;
лента в браузере понимает слова обоих языков.

## Документация на английском

`md_backend/документация/en/content.json` — те же статьи с теми же `slug`, `parent`, `order`,
`references`, `resource_type`, `status`; переводятся `title`, `summary_html`, `body_html`, `tags`,
`source_note`. В ссылках `[[slug|текст]]` и `[[число|текст]]` адрес не трогать. Код в `<code>`/`<pre>` —
как есть. Публикация: `php md_backend/документация/publish.php --lang=en`. Страница чтения показывает
язык человека; нет английской статьи — русскую.

## Проверка

```sh
PHP=/Applications/XAMPP/xamppfiles/bin/php
$PHP tests/v2/check-i18n.php                 # словари ru/en, ключи в коде, части файлов
$PHP tests/v2/check-i18n.php --left          # что осталось по-русски — по файлам
node tests/v2/check-golden.mjs               # ответы ведущему ru и en — буква в букву
node --check public/src/…/файл.js
$PHP -l lib/…/файл.php
```

`check-i18n.php` падает, если ключи ru и en расходятся, подстановки разные, ключ лежит не в файле своей
части, в английском тексте русские буквы или код зовёт ключ, которого нет в словаре.
